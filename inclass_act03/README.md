# 🚀 Cyber-Tactile Control Studio (Flutter)

A sleek, interactive 3D neomorphic control deck built with Flutter & Dart, demonstrating advanced micro-interactions and state management.

## ✨ Features
- **4 Mechanical Tactile Buttons**: Built using dual opposing `BoxShadow`s and `GestureDetector` for realistic push-button physicality.
- **Spaceship Cockpit Persona**: WARP (propulsion), SHIELDS (defense), SCANNER (sensors), and THRUSTER (maneuvering) controls, each with custom icons, labels, and accent colors.
- **Live State Management**: Real-time tap counter, energy level display, and active status banner.
- **80% Overload Warning**: Status banner switches to a red "OVERLOAD WARNING" state whenever the calibration slider crosses 80% power.
- **Adaptive Theming**: Seamless switching between Dark Cyber Mode and Light Ambient Mode.
- **Modular Component Design**: Reusable `TactileButton` custom widget architecture.

## 🛠 Tech Stack
- **Framework**: Flutter (Dart)
- **Language**: Dart
- **Key Widgets**: `StatefulWidget`, `GestureDetector`, `AnimatedContainer`, `Slider`, `Wrap`
